OpenAI retires whisper-1, gpt-4o-transcribe, gpt-4o-mini-transcribe and gpt-4o-transcribe-diarize on 26 February 2027: what to change

13 November 2026 · Driftline

On 26 February 2027, OpenAI removes whisper-1, gpt-4o-transcribe, gpt-4o-mini-transcribe and gpt-4o-transcribe-diarize from the API, together with its dated version. From that day, API calls to these models fail. OpenAI's recommended replacement (as of 14 November 2026): gpt-live-transcribe or gpt-transcribe.

What retires, and what replaces it

OpenAI lists these models on its deprecations page. The dates and replacements on this page come from Driftline's registry, which is checked against that page several times a day, so they stay current if OpenAI changes them.

More than a new model name

For these models, changing the name isn't the whole job:

  • OpenAI names two replacements: gpt-transcribe for recorded files, gpt-live-transcribe for live audio. Word timestamps, subtitles and translation work differently, so check those if you use them. OpenAI's guide

Find every place your code uses them

Run this in the root of your repository. No install, account or API key; it lists every OpenAI, Anthropic and Google model ID it finds, with file, line, retirement date and replacement:

npx -y @aidriftline/driftline .

A plain search works too:

grep -rnE '"(whisper-1|gpt-4o-transcribe|gpt-4o-mini-transcribe|gpt-4o-mini-transcribe-2025-12-15|gpt-4o-transcribe-diarize)"' .

It misses model names set outside the code: environment variables, deployment settings, values stored in a database, and defaults inside SDKs or agent frameworks you never configured.

Test before 26 February 2027

Run a handful of real requests on the replacement and compare the results with what you get today, before the date. Check the parts your code depends on: output format, quality, length and timing.

OpenAI retires gpt-5 and o3 on 11 December 2026: what to change and how to test it

12 November 2026 · updated 13 November 2026 · Driftline

On 11 December 2026, OpenAI removes gpt-5, gpt-5-mini, gpt-5-nano, gpt-5-pro, o3 and o3-pro from the API, together with their dated snapshots. From that day, API calls to these models fail. OpenAI's recommended replacements (as of 14 November 2026) are gpt-6.1-sol, gpt-6.1-terra and gpt-6-luna. Changing the model name takes a minute. Checking that your prompts still give the answers your app expects takes longer, and it can only be done while the old model still answers.

What retires, and what replaces it

OpenAI announced the shutdown on 11 June 2026 on its deprecations page. Both the short name and the dated snapshot stop working:

gpt-5-minigpt-5-mini-2025-08-07gpt-6.1-terra
gpt-5-nanogpt-5-nano-2025-08-07gpt-6-luna
gpt-5-progpt-5-pro-2025-10-06gpt-6.1-sol (reasoning.mode: pro, in the Responses API)
o3o3-2025-04-16gpt-6.1-sol
o3-proo3-pro-2025-06-10gpt-6.1-sol (reasoning.mode: pro, in the Responses API)

Changed: OpenAI changed these recommendations on 13 November 2026. Before, it recommended gpt-5.6-sol for gpt-5, gpt-5.6-terra for gpt-5-mini, gpt-5.6-luna for gpt-5-nano, gpt-5.6-sol for gpt-5-pro, gpt-5.6-sol for o3, gpt-5.6-sol for o3-pro. The table above shows the current advice; each model's page has the source.

Fine-tuned models built on any of these follow the same date, so an ID like ft:gpt-5-mini-2025-08-07:your-org::abc123 stops working on 11 December too. Note that o3 and o3-pro do not get an o-series successor: both move to gpt-6.1-sol.

Two other OpenAI shutdowns land just before. On 30 November the Evals platform and the reusable prompts API (v1/prompts) shut down, and on 1 December the older GPT Image models go. If you store prompts as prompt objects in OpenAI's dashboard, you have two migrations in the same two weeks.

Step 1: find every place your code uses them

Run this in the root of your repository. It needs no install, account or API key, and lists every OpenAI, Anthropic and Google model ID it finds with its file, line and retirement date:

npx -y @aidriftline/driftline .

A plain search works too, as long as you remember what it misses:

grep -rnE '"(gpt-5(-mini|-nano|-pro)?|o3(-pro)?)(-20[0-9-]+)?"' .

Places that are easy to overlook:

  • Environment variables and deployment settings, such as OPENAI_MODEL=gpt-5 in a .env file, a Helm chart or your hosting dashboard. These never show up in a code search.
  • Model names stored in a database, for example a per-customer or per-feature setting.
  • Defaults inside libraries and agent frameworks. If you never set a model, check which one your SDK or framework picks.
  • Evaluation scripts, notebooks and cron jobs that only run once a week.
  • Azure OpenAI deployments. Azure has its own retirement schedule, so check Azure's model retirement page for those.

Step 2: test your prompts before 11 December

A new model gives different answers to the same prompt. Usually they are fine, sometimes better. The problems show up where your code depends on the shape of the answer:

  • JSON that no longer matches your schema, or extra text around it
  • answers that are much longer or shorter, which matters for UI limits and cost
  • different tool or function calls for the same request
  • refusals on prompts that used to work
  • a different tone in customer-facing text

The test is simple. Take 10 to 20 real prompts from your logs, including the odd ones, run each on the old model and on the replacement, and compare the answers side by side. Check that every answer your code parses still parses.

The timing matters. After 11 December the old model is gone, so you can no longer see what it would have answered. You can only compare while both models respond, which means before 11 December. With the Evals platform shutting down on 30 November, OpenAI points to Promptfoo as one way to run such comparisons yourself.

Step 3: switch, then keep it from happening again

Change the model name, deploy the change well before 11 December, and watch your error logs for the first days. If you use gpt-5-pro or o3-pro, remember to set reasoning.mode: pro on gpt-6.1-sol (OpenAI: in the Responses API), otherwise you get the standard mode.

Questions

Will calls to gpt-5 keep working after 11 December 2026?

No. OpenAI removes the model from the API on that day, so requests to gpt-5 and gpt-5-2025-08-07 return an error. Unlike some Google models, these IDs are not quietly routed to a newer model.

Are gpt-5.1 and other GPT-5.x models affected?

Not on 11 December. gpt-5.1 and gpt-5.3-codex are scheduled to retire on 1 April 2027. Every date is on the model retirement list.

Does this affect ChatGPT?

This notice covers the API. Which models ChatGPT offers is a separate decision by OpenAI.

Is gpt-6.1-sol a drop-in replacement?

OpenAI names it as the recommended replacement, so in most code the change is the model name (plus the reasoning mode for the pro models). Check OpenAI's model page for any parameter differences. The answers are what change, which is why the prompt test in step 2 is worth an hour of your time.

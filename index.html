How it works

Three checks.
Every push.

Driftline runs as one step in your GitHub workflow. It reads your repository, compares what it finds with the providers' own retirement pages, and reports back on the pull request.

01 · Scan

Finds every model ID

Code, .env files and configs, in JavaScript, Python, Go and 20 more file types. It skips node_modules and build folders.

02 · Check

Knows the dates

Each ID is matched against the official OpenAI, Anthropic and Google retirement pages. You get a warning on the exact file and line.

03 · Test · Pro

Runs your prompts on both

Your saved prompts run on the current model and its replacement. Each one gets a similarity score, and a hard fail if JSON stops parsing.

Two minutes to install.

Add one workflow file. The scan is free and needs no key. For drift tests, activate your Pro key once with npx github:AI-Driftline/driftline activate and add your provider keys.

  • Annotations on the file and line of every retired or retiring model.
  • A report in the job summary, plus one GitHub issue that updates itself.
  • Fail the build on retired models, on soon-to-retire models, or never.
.github/workflows/driftline.yml
name: Driftline
on:
  schedule:
    - cron: "17 6 * * 1"   # every Monday
  pull_request:

jobs:
  driftline:
    runs-on: ubuntu-latest
    permissions: { contents: read, issues: write }
    steps:
      - uses: actions/checkout@v4
      - uses: AI-Driftline/driftline@v0
        with:
          create-issue: ${{ github.event_name != 'pull_request' }}
          fail-on: retired
          # Pro: license-key: ${{ secrets.DRIFTLINE_LICENSE_KEY }}

FAQ

Questions,
answered.

Does Driftline see my code or my API keys?

No. Driftline is a step inside your own GitHub Actions job. Prompts go from your runner straight to OpenAI, Anthropic or Google with your own keys. The only call Driftline makes for itself is the Pro license check with Lemon Squeezy, and that sends only the license key.

Where do the retirement dates come from?

From the providers' official deprecation pages, checked by hand and dated in the registry. Google lists only the earliest shutdown date, so those models are reported as "may stop working". Anthropic's "not sooner than" dates are shown for information and never fail a build.

Which models does it cover?

223 OpenAI, Anthropic and Google model IDs, including audio, image, video and embedding models. All of them are scanned and reported. Drift tests run on text models only.

What does a drift test cost me in API usage?

Two calls per prompt per run: one to the current model, one to the replacement. Ten prompts on a weekly schedule is 20 calls a week, billed by your provider on your own key. If the current model is already retired, only the replacement is called.

Can I use one Pro key in several places?

Yes, in every repository of up to 3 GitHub accounts or organizations, for example your own account and your company's. You activate the key once per account. To move a slot, deactivate one account and activate another. Need more? Write to hello@aidriftline.com.

What happens if I cancel Pro?

Drift tests stop at the end of your paid period. The free scan keeps running. You can cancel any time from the Lemon Squeezy receipt email, and you can ask for a full refund within 14 days of your first payment.

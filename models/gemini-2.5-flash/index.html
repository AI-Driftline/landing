gemini-2.5-flash

On 1 December 2026, Google starts routing API requests for gemini-2.5-flash to gemini-3.5-flash-lite. Calls to gemini-2.5-flash will keep succeeding, but the answers will come from a different model.

Before you switch

A replacement model answers the same prompt differently: tone, length, format, and whether JSON still parses. Driftline Pro runs your real prompts on gemini-2.5-flash and gemini-3.5-flash-lite side by side in CI and shows what changed. See a drift test.

Check your code for it

Run this in your repository. No install and no API key; it lists every OpenAI, Anthropic and Google model ID it finds, with its retirement date and replacement:

npx -y github:AI-Driftline/driftline .

Or look for this ID only: grep -rn "gemini-2.5-flash" . (misses aliases, Bedrock and Vertex names, and IDs split across lines).

How Driftline tells Azure from OpenAI's API

Azure uses OpenAI's model names. Driftline uses Azure's dates in files that show they call Azure: AzureOpenAI, azure_endpoint, openai.azure.com, AZURE_OPENAI_…, azure/ model names, and Bicep or Terraform deployments, where it also reads the model version (never api_version). Elsewhere it uses OpenAI's dates and notes when Azure's differ.

Get an email before it retires

One email 30 days before, one 7 days before and one on the day, plus a note if Azure changes the date. Nothing else. One-click unsubscribe.

How Driftline tells Vertex from the Gemini API

Vertex uses the same model names as the Gemini API and Anthropic. Driftline uses Vertex's dates in files that show they run on Vertex: vertexai=True, vertexai or google.cloud.aiplatform imports, @google-cloud/vertexai, AnthropicVertex, vertex_ai/ model names, Claude's @date spelling and -maas IDs. Elsewhere it uses the Gemini API's dates and notes when Vertex's differ.

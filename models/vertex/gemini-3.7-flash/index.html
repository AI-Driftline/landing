How Driftline tells Vertex from the Gemini API

Vertex uses the same model names as the Gemini API. Driftline uses Vertex's dates in files that show they run on Vertex: vertexai=True, vertexai or google.cloud.aiplatform imports, @google-cloud/vertexai, AnthropicVertex, vertex_ai/ model names, Claude's @date spelling and -maas IDs. Elsewhere it uses the Gemini API's dates and notes when Vertex's differ.

Get an email before it retires

One email 30 days before, one 7 days before and one on the day, plus a note if Vertex AI changes the date. Nothing else. One-click unsubscribe.

Check your code for it

Run this in your repository. No install and no API key; it lists every OpenAI, Anthropic, Google, Mistral, xAI, Cohere, DeepSeek, Groq, Bedrock, Vertex AI and Azure model ID it finds, with its retirement date and replacement:

Model retirement dates / OpenAI

gpt-5-nano

OpenAI will retire gpt-5-nano on 11 December 2026. After that date, API calls to it fail. The recommended replacement is gpt-6-luna. OpenAI changed this recommendation on 13 November 2026; before, it was gpt-5.6-luna.

Before you switch

A replacement model answers the same prompt differently: tone, length, format, and whether JSON still parses. Driftline Pro runs your real prompts on gpt-5-nano and gpt-6-luna side by side in CI and shows what changed. See a drift test.

Get an email before it retires

One email 30 days before, one 7 days before and one on the day, plus a note if OpenAI changes the date. Nothing else. One-click unsubscribe.

Check your code for it

Run this in your repository. No install and no API key; it lists every OpenAI, Anthropic, Google, Amazon Bedrock and Vertex AI model ID it finds, with its retirement date and replacement:

npx -y @aidriftline/driftline .

Or look for this ID only: grep -rn "gpt-5-nano" . (misses aliases, Bedrock and Vertex names, and IDs split across lines).

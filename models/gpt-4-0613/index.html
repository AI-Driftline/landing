Before you switch

A replacement model answers the same prompt differently: tone, length, format, and whether JSON still parses. Driftline Pro runs your real prompts on gpt-5.6-sol in CI, so you see the new answers before you ship the switch. See a drift test.

Check your code for it

Run this in your repository. No install and no API key; it lists every OpenAI, Anthropic and Google model ID it finds, with its retirement date and replacement:

npx -y github:AI-Driftline/driftline .

Or look for this ID only: grep -rn "gpt-4-0613" . (misses aliases, Bedrock and Vertex names, and IDs split across lines).
